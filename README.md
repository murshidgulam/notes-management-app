# Notes Management App 📝

A simple notes management application built as part of my journey learning backend web development.

## Features

* Create and save notes
* View saved notes
* Read individual notes
* Rename existing notes

## Tech Stack

* Node.js
* Express.js
* EJS
* Tailwind CSS
* Node.js File System module

## What I Learned

* Handling HTTP requests with Express.js
* Rendering dynamic pages using EJS
* Working with files using Node.js
* Building a simple backend application

## How to Run Locally

1. Clone the repository.
2. Install dependencies using `npm install`.
3. Run the application using `node index.js`.
4. Open the local URL configured by the application in your browser.
